📖 Cara Setup Google Apps Script
1
Buat Google Spreadsheet baru
Buka Google Drive → New → Google Sheets. Beri nama sesuai keinginan (contoh: "Abu Khaisa Keuangan").
2
Buka Apps Script
Di Spreadsheet, klik menu Extensions → Apps Script. Hapus kode yang ada, lalu paste kode Apps Script di bawah.
3
Deploy sebagai Web App
Klik Deploy → New Deployment → Web App. Set Execute as: "Me", Who has access: "Anyone". Klik Deploy.
4
Salin URL Web App
Setelah deploy, salin URL yang muncul (format: https://script.google.com/macros/s/.../exec)
5
Tempel URL di Abu Khaisa
Paste URL tersebut di kolom konfigurasi di atas, lalu klik Hubungkan.
